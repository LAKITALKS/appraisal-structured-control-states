## Current state

v0.1.2 is an unreleased methodological correction to the archived v0.1.1

## Correction completed (first pass)

- The non-identifying historical B/C H1 statistic is explained and demoted to a
  non-deciding diagnostic.
- H1 now uses bidirectional cross-mention transfer within outer LODO folds, with
  whole matched groups confined to one side of every boundary.
- Nested layer and regularization selection is limited to outer-training domains.
- H1 task-state transfer and H2 incremental value are separate gates.
- The unresolved frozen prompt-embedding comparator is represented by blocking
  sentinels and an explicit author decision.
- The final-token semantics and Layer-0 user-content pooling rule are specified.
- Technical smoke artifacts are structurally ineligible for scientific analysis.
- Axis-isolation QA records the observed factor values and explicit absence of the
  two non-target primary axes.
- H1, H2, H3, and family-structure comparison families are separated; unresolved
  layer/intervention grids remain visible decision blocks.
- Versions and archival metadata are corrected without changing historical tags,
  releases, records, or DOIs.

## Correction completed (second pass, after the independent audit)

An independent read-only scientific, statistical, technical, and PDF audit
confirmed the principal correction and identified remaining specification gaps.
Each is resolved:

- **H2 target bound.** The primary H2 target is the four registered
  response-strategy superclasses (`direct_or_comply`, `qualify_or_warn`,
  `redirect_or_clarify`, `decline_or_abstain`), with the nine fine labels
  secondary, labels from the registered meaning-based protocol, and H2 inference
  withheld if the label-reliability gate fails. H2 is not a second task-state test.
- **H2 estimand, sign, and decision rule bound.**
  `delta_H2 = log_loss_prompt_embedding - log_loss_hidden_state`, so positive
  favors the hidden state; lower limit above 0 is positive feasibility, upper limit
  at or below 0 is weakened once all gates pass, overlap is indeterminate. The
  secondary balanced-accuracy difference uses hidden state minus prompt embedding.
- **Estimability bound.** A single-superclass outer-training fold yields
  `NOT_ESTIMABLE`, which is indeterminate rather than positive; classes are never
  merged post-data; unseen test classes are reported as generalization failures
  under a fixed float64 clipping rule applied identically to both classifiers; no
  observation is silently excluded. Mini-0 supports only single-axis H2 feasibility.
- **Probe specification frozen.** Training-subset-only `StandardScaler`, L2 logistic
  regression with `lbfgs`, intercept, no class weighting, `max_iter=5000`,
  `tol=1e-6`, float64, and the grid `C ∈ {1e-4, 1e-3, 1e-2, 1e-1, 1, 10, 100}`.
  Prompt-embedding pooling and normalization precede the classifier pipeline;
  sparse baselines stay secondary and sparse-safe.
- **Selection objectives and tie-breaks frozen**, with one numerical tie tolerance
  (`1e-12`). The layer candidate grid remains a visible run blocker.
- **Inner validation replaced** with deterministic inner
  leave-one-training-domain-out: three inner folds per outer fold, two fit domains,
  one validation domain, crossed concept direction, disjoint matched groups.
- **Seed roles frozen:** primary `0`; sensitivity `1–4`; bootstrap `20260830`;
  permutation `20260831`. No pooling across seeds; splits do not vary by seed.
- **Bootstrap specified exactly:** 1,000 resamples of complete matched-group
  clusters, stratified within each held-out domain, group predictions travelling
  together, four out-of-fold predictions per group for pooled H1, paired losses
  resampled together for H2, percentile interval at 2.5%/97.5%.
- **FDR made operational:** BH at `q = 0.05` over preregistered one-sided raw
  p-values — a matched-group task-state-label-swap randomization test for H1's
  16-member secondary family and a paired model-block exchange permutation test for
  H2's 8-member secondary family, each with 10,000 permutations, the `+1`
  correction, and the frozen permutation seed. No document calls a confidence
  interval FDR-corrected; the historical v0.1.1 "after FDR" wording is preserved
  and the conflict is explained rather than rewritten.
- **Manifest guards tightened:** `experiment_id` and `stimulus_file_hash` added to
  compatibility with no duplicated field names; timestamp, output directory, shard
  identity, and seed still excluded; full 40-character lowercase hexadecimal
  commit revisions required for scientific runs; `sha256:<64 hex>` format enforced;
  explicit `NOT_APPLICABLE_TECHNICAL_SMOKE` prompt-embedding fields allowed only
  for smoke runs; the integrated pre-run gate added for the future runner.
- **One canonical release build established** (see below).

## Correction completed (final pre-release review)

- **Stage-aware gates.** Mini-0 no longer depends on the later H3 intervention grid;
  H3 retains its own explicit stage gate.
- **Authoritative four-artifact authorization.** Config, frozen Mini-0 run plan,
  immutable manifest, and canonical typed stimulus payload must all pass and agree.
  A config-only helper is permanently fail-closed. Experiment ID, full 40-hex
  revisions, code commit, stimulus hash, chat-template identity/hash, embedding
  details, target axis, grids, and raw-p procedure are checked before model
  construction.
- **Mini-0 stimulus scope enforced.** Only the uncertainty axis is eligible; all
  four registered domains must appear; at least 40 complete run-ready groups are
  required; domain group counts may differ by at most one. Split and bootstrap
  planners reject mixed axes and missing domains.
- **H2 selection made symmetric and explicit.** Hidden states independently select
  `(layer, C)` and prompt embeddings independently select `C` on the same inner
  folds, items, target, and log-loss objective; smaller-`C` ties are resolved
  separately and the earlier-layer tie-break is hidden-state-only.
- **H2 estimability completed.** Single-class inner or final fits and exhaustion of
  converged candidates make the outer fold `NOT_ESTIMABLE`; any required such fold
  makes the aggregate indeterminate. Four-class probability columns are aligned and
  zero-filled before identical clipping and renormalization.
- **Response-label reliability operationalized.** The primary human labels all
  responses; a second independent human labels a deterministic, domain-stratified
  `ceil(0.30 × N_groups)` complete-group subset selected before labels (seed
  `20260901`). Pre-adjudication Cohen's kappa must be at least 0.60; raw agreement,
  confusion matrix, class counts, and matched-group bootstrap CI are mandatory;
  failure or fewer than two classes withholds H2 and H3.
- **Family rule repaired in YAML.** A requires a raw interval below zero; B and C
  require raw intervals above zero; all three also require BH-adjusted one-sided raw
  p-values. The stale generic one-sign rule is gone.
- **Seed contradiction removed.** LODO split assignments are deterministic and are
  no longer listed among seed-governed quantities.
